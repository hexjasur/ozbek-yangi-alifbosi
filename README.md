# Yangi O'zbek Alifbosi — Onlayn Harflar Nusxalash va Matn O'girgich 🇺🇿

> Yangi o'zbek lotin alifbosi islohoti harflari (**Ö, ö, Ğ, ğ, Ç, ç, Ş, ş**) uchun qulay, tezkor onlayn nusxalash va matn konvertori.

## 🚀 Imkoniyatlari

- **Tezkor Nusxalash:** Yangi harflarning katta va kichik shakllarini bir marta bosish orqali xotiraga olish (Clipboard).
- **Ikki Tomonlama O'girgich (Konvertor):**
  - Eski yozuvdan yangi yozuvga (`O'` → `Ö`, `G'` → `Ğ`, `Ch` → `Ç`, `Sh` → `Ş`)
  - Yangi yozuvdan eski yozuvga qaytarish
- **SEO & Google Qidiruvga Mos:** Meta teglar, Open Graph, Twitter kartalari va Schema.org JSON-LD structured data integratsiyasi.
- **Tez va Yengil:** Hech qanday og'ir kutubxonalarsiz, sof Tailwind CSS va zamonaviy JavaScript.
- **Moslashuvchan Dizayn (Responsive):** Mobil telefonlar, planshetlar va kompyuterlarda ideal ko'rinish.
- **Xavfsiz va 100% Bepul.**
